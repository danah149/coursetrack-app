# CourseTrack 📱

## About The Project
**CourseTrack** is a modern Android application developed as part of an academic project (IT487) at Saudi Electronic University. The application is designed to help students efficiently manage academic courses, track schedules, and organize daily tasks.

## Tech Stack & Configuration
* **Language:** Kotlin
* **Platform:** Android (AndroidX)
* **Build System & DSL:** Gradle Kotlin DSL (`.kts`)
* **Environment:** Android Studio
* **Build Optimizations:** Configured with non-transitive R classes and optimized JVM memory arguments for high-performance builds.

## Key Features
* Structured academic course management.
* Clean architecture utilizing modern Android plugins and dependencies.
* Optimized build configuration for better performance and maintainability.

## Future Enhancements
* Integrating local database storage (Room/SQLite) for persistent data handling.
* Implementing a clean, intuitive user interface for tracking academic tasks.
